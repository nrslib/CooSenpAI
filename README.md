# CooSenpAI

指示のいらないAI

<sub>Coo — Seeing, Encouraging, Nudging, Pleasure AI</sub>

CooSenpAIはmacOSの画面を見守り、必要なときに声をかけるAIです。

## できること

### 見ているものをAIに

画面の気になる部分はスクリーンショットで、文章はコピーで、その場のAIに渡せます。文字を打つより早いときは、声で話しかけることもできます。

### AIが気づいて声かけ

困っていそうな場面では、AIが吹き出しで短く声をかけます。見てほしいアプリは自分で選べます。

### AIのイライラを最小限に

コピーした文章を貼り直したり、作業中のアプリから離れたり、状況を一から説明したりしなくて済みます。

## 必要なもの

- macOS 13以降を搭載したApple Silicon Mac
- Claude Code、Codex、OpenCodeのいずれか

## インストール

[Releases](https://github.com/nrslib/CooSenpAI/releases)からdmgをダウンロードしてインストールします。
